개인정보 처리 안내

시행일: 2026년 9월 30일

스모아카이브(이하 "사이트")는 개인이 운영하는 비영리 스모 팬 사이트입니다. 회원가입이 없고, 사이트를 운영하는 데 꼭 필요한 정보만 다룹니다. 어떤 정보를 왜, 얼마 동안 보관하는지 아래에 안내합니다.

1. 다루는 정보와 목적

정보목적보관 기간
댓글의 닉네임, 내용, 작성 시각 댓글 게시 댓글이 게시되어 있는 동안
댓글 삭제용 비밀번호(숫자 4자리) 작성자 본인 삭제 확인 원래 값을 알 수 없는 형태(해시)로만 저장하며, 댓글이 게시되어 있는 동안
댓글 신고 횟수와 마지막 신고 시각 관리자의 댓글 검토 댓글이 게시되어 있는 동안 (신고한 사람의 정보는 저장하지 않음)
접속 IP 주소 댓글 도배, 비밀번호 무차별 대입, 신고 남용 방지 서버 메모리에만 최대 24시간 (데이터베이스에 저장하지 않음)
서버 접속 기록 (IP 주소, 요청 주소, 시각, 브라우저 정보) 보안 사고와 장애 대응 14일 후 자동 삭제

2. 댓글 삭제와 파기

  • 작성자가 비밀번호로 댓글을 삭제하면 닉네임, 내용, 비밀번호를 즉시 지웁니다. 목록에는 "작성자에 의해 삭제된 댓글입니다"라는 표시만 남습니다.
  • 관리자가 가림 처리한 댓글은 신고 대응과 재발 방지를 위해 원문을 보관합니다. 아래 문의처로 요청하면 삭제합니다.
  • 장애 복구를 위한 데이터베이스 백업은 14일간 보관되므로, 삭제한 정보도 이 기간 동안은 백업에 남아 있을 수 있습니다.

3. 쿠키와 브라우저 저장소

  • 세션 쿠키 (JSESSIONID): 고른 언어(한국어/일본어)를 기억하는 데 씁니다. 브라우저를 닫으면 사라집니다.
  • 브라우저 저장소 (localStorage): 즐겨찾기 목록과 차트 보기 설정은 방문자의 브라우저에만 저장되고 서버로 보내지 않습니다. 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.
  • 방문 분석이나 광고를 위한 쿠키는 쓰지 않습니다.

4. 외부 서비스

화면을 표시하기 위해 아래 외부 서비스를 씁니다. 페이지를 열면 방문자의 브라우저가 이 서비스들에 직접 접속하므로, IP 주소와 브라우저 정보가 각 사업자에게 전달되고 각 사업자의 개인정보 처리방침이 적용됩니다.

  • Google Fonts (Google): 글꼴
  • cdnjs (Cloudflare): 리키시 페이지의 차트 기능
  • jsDelivr: 즐겨찾기 순서 바꾸기 기능
  • YouTube (Google): 경기 하이라이트 영상. 쿠키를 줄인 youtube-nocookie.com 주소로 불러오며, 영상을 재생하면 YouTube의 정책이 적용됩니다.

이 밖에 다루는 정보를 다른 곳에 제공하지 않습니다. 다만 법령에 따른 요청이 있으면 그에 따릅니다.

個人情報の取り扱い

施行日：2026年9月30日

相撲アーカイブ（以下「本サイト」）は、個人が運営する非営利の相撲ファンサイトです。会員登録はなく、 運営に必要な情報だけを扱います。どの情報をなぜ、どのくらいの期間保存するかを以下にご案内します。

1. 取り扱う情報と目的

情報目的保存期間
コメントのニックネーム・内容・投稿日時 コメントの掲載 コメントが掲載されている間
コメント削除用の暗証番号（数字4桁） 投稿者本人による削除の確認 元の値を復元できない形式（ハッシュ）でのみ保存し、コメントが掲載されている間
コメントの通報回数と最終通報日時 管理者によるコメントの確認 コメントが掲載されている間（通報した方の情報は保存しません）
接続元IPアドレス 連続投稿・暗証番号の総当たり・通報の乱用の防止 サーバーのメモリ上でのみ最大24時間（データベースには保存しません）
サーバーのアクセス記録（IPアドレス、アクセス先、日時、ブラウザ情報） セキュリティ事故・障害への対応 14日後に自動削除

2. コメントの削除と廃棄

  • 投稿者が暗証番号でコメントを削除すると、ニックネーム・内容・暗証番号をただちに消去します。一覧には「投稿者により削除されたコメントです」という表示だけが残ります。
  • 管理者が非表示にしたコメントは、通報への対応と再発防止のため原文を保存します。下記のお問い合わせ先にご依頼いただければ削除します。
  • 障害復旧用のデータベースのバックアップは14日間保存されるため、削除した情報もその期間はバックアップに残る場合があります。

3. Cookieとブラウザのストレージ

  • セッションCookie（JSESSIONID）：選んだ表示言語（韓国語／日本語）を覚えておくために使います。ブラウザを閉じると消えます。
  • ブラウザのストレージ（localStorage）：ごひいき一覧とグラフの表示設定は、お使いのブラウザにだけ保存され、サーバーには送信しません。ブラウザのサイトデータ削除で消去できます。
  • アクセス解析や広告のためのCookieは使用していません。

4. 外部サービス（外部送信）

画面の表示のために以下の外部サービスを利用しています。ページを開くと、お使いのブラウザがこれらのサービスに直接接続するため、IPアドレスやブラウザ情報が各事業者に送信され、各事業者のプライバシーポリシーが適用されます。

  • Google Fonts（Google）：フォント
  • cdnjs（Cloudflare）：力士ページのグラフ機能
  • jsDelivr：ごひいきの並べ替え機能
  • YouTube（Google）：取組のハイライト動画。Cookieを抑えた youtube-nocookie.com で読み込み、動画を再生するとYouTubeのポリシーが適用されます。

これ以外に、取り扱う情報を第三者に提供することはありません。ただし、法令に基づく要請がある場合はそれに従います。
