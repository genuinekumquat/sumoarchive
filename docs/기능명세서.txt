========================================
통합 기능명세서
한국어 사용자를 위한 스모 정보/분석 플랫폼 (최종본)
========================================


----------------------------------------
0. 공통 권한 및 시스템 정의
----------------------------------------

[일반 사용자 (비회원)]
- 로그인/가입 없음. 전체 정보(반즈케, 프로필, 경기 결과 등) 자유롭게 조회.
- 익명 댓글 작성 및 본인 댓글 삭제 (비밀번호 검증 방식).
- 관심 리키시 및 토리쿠미 북마크 기능 사용 (Local Storage 활용으로 DB 부하 제로).

[사이트 관리자]
- 별도 메뉴 노출 없이 특정 주소(https://도메인/admin/login) 직접 입력으로 로그인 페이지 접근.
- 관리자 로그인 성공 시 세션(Session)에 isAdmin=true 부여하여 필터/인터셉터로 /admin/ 경로 제어
  (Spring Security 배제, 경량화 구현).
- 관리자 전용 기능: 데이터 수동 갱신, 전체 댓글 무조건 삭제 및 블라인드 가림 처리.


----------------------------------------
1. 메인 화면 (최신 반즈케 대시보드)
----------------------------------------

- 현시점 기준 최신 반즈케(등급표)를 메인에 노출하며, 공식 반즈케 발표일에 맞춰 관리자가 데이터 동기화 수행.

[UI/UX 규칙]
- 화면 상단에 디비전 탭 존재: 마쿠우치, 주료, 마쿠시타, 산단메, 조니단, 조노구치
- 탭 클릭 시: 해당 디비전에 속한 리키시들을 반즈케 서열 순서(등급 순 및 동/서 서열 순)로 정렬하여
  화면에 노출 (비동기 Fetch 조회 방식 권장).
- 리키시 이름 클릭 시: 해당 선수의 리키시 프로필 화면으로 이동.


----------------------------------------
2. 검색창 및 검색 결과 화면
----------------------------------------

- 검색어 하나로 한국어 시코나, 일본어 시코나, 과거 사용했던 이전 시코나(이력)까지 통합 검색을 지원.
  동명이인 및 대물림 시코나 예외 케이스를 완벽 대응.

[검색 작동 메커니즘]
- 검색창에 키워드 입력 후 엔터 또는 검색 버튼 클릭 시 무조건 검색 결과 목록 화면
  (/search?keyword=검색어)으로 이동.
  (바로 상세 페이지 리다이렉트 안 함으로써 일관된 UX 유지 및 브라우저 뒤로 가기 꼬임 방지)

[검색 결과 목록 UI/UX]
- 검색된 선수가 1명뿐이더라도 목록 페이지에 1건의 카드로 노출하여 유저의 예측 가능성 확보.
- 동명이인/대물림 시코나 구분 힌트 제공: 검색 리스트 카드 내에
  [실명, 활동 시기(데뷔~은퇴년도), 최고 계급, 현재 상태(현역/은퇴/오야카타 습명)]을
  한눈에 보여주어 유저가 직접 구분하고 클릭하여 진입할 수 있도록 유도.


----------------------------------------
3. 리키시 프로필 화면
----------------------------------------

[기본 정보]
- 현재 시코나(이전 이름 변경 이력 텍스트 포함), 본명, 생년월일(나이 계산 출력), 출신지, 국적,
  소속 헤야, 키, 체중, 현재 계급, 최고 계급, 현역 여부
  (은퇴 시 은퇴일 및 오야카타 습명 이름 노출).
- 파이팅 스타일: 오시(押し), 요츠(四つ), 믹스, Unorthodox 등 관리자 어드민에서 지정 입력한 텍스트 노출.

[커리어 레코드]
- 통산 전적(승/패/무), 우승(유쇼) 횟수, 킨보시(金星) 획득 개수, 삼상(산쇼) 수상 이력.
- 키마리테(결정 기술) 분석: 해당 선수가 승리한 모든 판의 기술 통계를 바탕으로
  원형 차트(Pie/Donut Chart) 시각화.

[역대 커리어 호시토리(星取)표]
- 선수가 데뷔해서 지금까지 거쳐온 모든 바쇼의 성적표
  (연도.월별 계급, 일차별 승○/패●/휴장- 결과)를 타임라인 테이블 형태로 출력.
- UI/UX 하이퍼링크 규칙: 호시토리표 내의 각 일차별 개별 경기 결과 아이콘(○, ● 등) 클릭 시,
  해당 경기의 토리쿠미 상세 페이지로 즉시 이동 처리 (유저 탐색 편의성 극대화).


----------------------------------------
4. 북마크 페이지
----------------------------------------

- 로그인/회원가입 없이 유저가 좋아하는 최애 리키시들을 모아놓고
  본인만의 커스텀 목록을 구성하는 마이페이지 성격의 화면.

[구현 방식 (Local Storage 기반)]
- 리키시 상세 페이지 내 [★ 북마크] 버튼 제공.
  클릭 시 브라우저 LocalStorage 내에 해당 리키시 ID 배열(예: [3, 15, 24]) 추가/삭제 처리.

[북마크 목록 및 정렬]
- 1단계 (목록 조회): 북마크 페이지 진입 시 Local Storage의 ID 배열을 서버에 던져
  (GET /api/rikishiEntity?ids=3,15,24) 해당 선수 카드 목록을 렌더링.
- 2단계 (순서 변경): 프론트엔드 드래그 앤 드롭 라이브러리(예: SortableJS)를 활용하여
  마우스 드래그로 선수 카드 순서를 스왑. 변경된 최종 ID 순서 배열을 Local Storage에 다시 저장하여
  나만의 최애 리키시 랭킹 리스트 구현.


----------------------------------------
5. 토리쿠미(경기) 상세 페이지 & 분석 댓글창
----------------------------------------

[조회 항목]
- 대회 정보: 개최 연도/월, 어떤 바쇼(예: 7월 나고야 바쇼)의 몇 일째(◯일목) 시합인지 정보 노출.
- 대진 정보: 동(東) 리키시 vs 서(西) 리키시 매칭 정보, 경기 결과(승패) 시각적 강조,
  결정 기술(키마리테) 한/일 명칭 노출.
- 미디어: 해당 경기의 유튜브 하이라이트 영상 임베드 또는 외부 링크 제공.

[익명 댓글창 - 입력 유효성 검사]
- 닉네임: 필수 입력, 최대 8자 제한.
- 비밀번호: 필수 입력, 숫자 4자리 제한 (차후 본인 삭제용).
- 댓글 내용: 필수 입력, 최대 200자 제한, 공백만 입력 시 등록 불가 처리.
- 안내 문구: "선 넘는 비방이나 욕설은 관리자에 의해 예고 없이 가림 처리 또는 삭제될 수 있습니다." 노출.
- 수정 제한: 익명 댓글 특성상 수정 기능은 제공하지 않음.

[삭제 로직 - 소프트 딜리트 적용]
- 일반 사용자: 본인 댓글의 [삭제] 버튼 클릭 → 비밀번호 4자리 입력 → 일치 시
  DB comment.is_deleted 값을 true로 업데이트 (소프트 딜리트).
  화면에는 "작성자에 의해 삭제된 댓글입니다"로 노출하여 레이아웃 유지.
- 관리자: 관리자 로그인 세션 상태일 경우, 비밀번호 검증 없이 즉시 삭제 권한 보유.
  해당 댓글 내용을 "관리자에 의해 블라인드 처리된 댓글입니다"로 즉시 가림 처리(is_deleted = true).
